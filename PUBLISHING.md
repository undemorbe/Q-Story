# Публикация в Google Play

Памятка с готовыми ответами для форм Play Console. Всё, что проверяется автоматически, покрыто тестом [`test/release_readiness_test.dart`](test/release_readiness_test.dart).

## Материалы страницы

Лежат в [`fastlane/metadata/android`](fastlane/metadata/android) (`ru-RU`, `en-US`), в формате [fastlane supply](https://docs.fastlane.tools/actions/supply/) — можно загрузить вручную или командой `fastlane supply --skip_upload_aab`.

| Что | Файл |
|---|---|
| Название (≤ 30) | `title.txt` |
| Краткое описание (≤ 80) | `short_description.txt` |
| Полное описание (≤ 4000) | `full_description.txt` |
| Что нового (≤ 500) | `changelogs/<versionCode>.txt` |
| Значок 512 × 512 | `images/icon.png` |
| Баннер 1024 × 500 | `images/featureGraphic.png` |
| Скриншоты 1080 × 1920 | `images/phoneScreenshots/` |

Скриншоты генерируются из приложения с демо-данными:

```bash
flutter test test/screenshots --dart-define=SCREENSHOTS=true
```

## Ответы для Play Console

**Категория:** Путешествия и местные достопримечательности. **Реклама:** нет. **Целевая аудитория:** 13+ (приложение не рассчитано на детей). **Политика конфиденциальности:** https://github.com/undemorbe/Q-Story/blob/main/PRIVACY.md

**Безопасность данных (Data safety)**

| Вопрос | Ответ |
|---|---|
| Собирает или передаёт данные | Да — только местоположение |
| Местоположение (приблизительное и точное) | Собирается, не передаётся третьим лицам для их целей; обрабатывается мгновенно (координаты области карты уходят в открытые API, чтобы получить места рядом); необязательно; цель — функциональность приложения |
| Шифрование при передаче | Да (HTTPS) |
| Удаление данных по запросу | Разработчик ничего не хранит; локальные данные удаляются в приложении (*Статистика → Сбросить*) или вместе с приложением |
| Физическая активность (шаги), маршруты, фото, контакты, идентификаторы | Не собираются — остаются на устройстве |

**Разрешения**

| Разрешение | Зачем | Что заполнить |
|---|---|---|
| `ACCESS_FINE_LOCATION` | места рядом, охота, маршрут | — |
| `FOREGROUND_SERVICE_LOCATION` | запись прогулки при выключенном экране, только если пользователь включил «Фоновый трекинг» | декларация Foreground service: тип *Location*, видео с включением настройки и уведомлением |
| `ACTIVITY_RECOGNITION` | шагомер | — |
| `CAMERA` | сканирование QR-кодов | — |
| `POST_NOTIFICATIONS` | ежедневное напоминание, запрашивается при включении | — |

`ACCESS_BACKGROUND_LOCATION` и точные будильники не используются, отдельные декларации для них не нужны.

**Возрастной рейтинг:** в анкете на всё «нет» (нет насилия, азартных игр, общения между пользователями, покупок) — ожидаемо 3+ / Everyone. **Приложение для здоровья:** нет (шаги — часть игровой механики прогулок, данные не покидают устройство).

## Выпуск версии

1. Поднять `version:` в `pubspec.yaml` (и `AppInfo.version`), дописать `CHANGELOG.md` и `fastlane/metadata/android/*/changelogs/<versionCode>.txt`.
2. `flutter test` — тест готовности сверит версии и лимиты.
3. Создать тег, workflow [`release.yml`](.github/workflows/release.yml) соберёт подписанный AAB:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

4. Загрузить AAB из GitHub Release в Play Console (первый раз — во внутреннее тестирование). Для подписи используется Play App Signing; ключ загрузки задаётся секретами репозитория, перечисленными в `release.yml`.
