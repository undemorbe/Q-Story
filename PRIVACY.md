# Политика конфиденциальности QStory

_Действует с 8 ноября 2026 г._

QStory не собирает и не передаёт разработчикам никаких персональных данных. У приложения нет своего сервера, аккаунтов, рекламы и аналитики.

## Какие данные используются и где они хранятся

| Данные | Зачем | Где хранятся | Куда передаются |
|---|---|---|---|
| Геопозиция | показать места рядом, вести маршрут, засчитать найденное место | только на устройстве | координаты и радиус — в запросах к включённым источникам мест (см. ниже) |
| Шаги (датчик движения) | статистика шагов и поисков | только на устройстве | никуда |
| Маршрут, визиты, поиски, избранное, свои места | статистика и журнал | только на устройстве | никуда |
| Камера | сканирование QR-кодов | кадры не сохраняются | никуда |
| Настройки | тема, язык, цели, время напоминания | только на устройстве | никуда |
| Уведомления | ежедневное напоминание с фактом (если включено); список уже показанных фактов | планируются и хранятся на устройстве | никуда |

## Внешние сервисы

Чтобы найти места рядом, приложение отправляет координаты и радиус поиска в те источники, которые вы включили в настройках:

- PastVu — https://pastvu.com
- Википедия / MediaWiki API — https://www.wikipedia.org (Wikimedia Foundation)
- Wikidata Query Service — https://query.wikidata.org (Wikimedia Foundation)
- OpenStreetMap Overpass API и его зеркала
- Тайлы карты — tile.openstreetmap.org (OpenStreetMap Foundation)
- Раздел «История дня» — ru.wikipedia.org, лента «В этот день» (передаётся только дата, без координат)
- Напоминания — ru.wikipedia.org / en.wikipedia.org по языку приложения: блок «Знаете ли вы?» и избранные события «В этот день» (передаются только язык и даты, без координат); факты о местах рядом берутся из локального кэша, без запросов

Эти сервисы видят ваш IP-адрес и запрос, как при открытии сайта в браузере, и обрабатывают их по своим политикам. Источник можно выключить в настройках.

Отправка отзыва или жалобы открывает ваш почтовый клиент с готовым письмом — вы сами решаете, отправлять ли его.

«Поделиться» местом, «Пешком туда» и экспорт статистики передают данные только в выбранное вами приложение (мессенджер, навигатор, файлы) и только по вашему нажатию.

Шрифты встроены в приложение, поэтому к Google Fonts запросов нет.

## Фоновая геолокация

Включается только вручную (*Настройки → Трекинг → Фоновый трекинг*). На Android в это время видно постоянное уведомление. Выключается там же.

## Удаление данных

*Статистика → Сбросить статистику* стирает шаги, маршруты, визиты и поиски. Удаление приложения стирает всё.

## Дети

Приложение не предназначено для сбора данных о детях и не собирает их.
